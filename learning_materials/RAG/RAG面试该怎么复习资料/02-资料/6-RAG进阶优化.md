## 3 RAG自研技术架构

### 3.1 FAQ和RAG

问答对（FAQ）vs RAG（检索增强生成）

**双层知识库问答**

**第一层：****FAQ****知识库（人工标注）**：这是一个高质量、小而精的知识库，存储着由领域专家撰写和审核的标准问答对。它专门针对那些频繁发生、具有标准问答对的回答。这一层的目标是提供"零偏差"的答案。

**第二层：向量知识库（文档语料）**：这是一个大规模、广覆盖的知识库，包含了操作手册、行业规范、领域文档等海量非结构化文档。通过文本分割、向量化后存储于向量数据库中。它负责处理FAQ知识库未覆盖的长尾问题和复杂查询。

**一、什么是** **MinerU**

- •开源工具，由 OpenDataLab 开发（InternLM 的预训练过程中诞生）。
- •能将 PDF 文档转换为机器可读格式（Markdown / JSON 等）。
- •重点面向保留文档结构与内容完整性（包括图片、公式、表格等）。

**二、项目概况**

- •开源项目，Github Star：52.7K+（持续增长中）
- •每个月100+ 活跃贡献者
- •Issues：快速响应，平均24小时内回复
- •支持多语言文档和社区
- •项目的主页为：https://github.com/opendatalab/MinerU
- •项目的网站为：https://mineru.net/
- •开发团队：上海人工智能实验室 · OpenDataLab



**三、核心功能**

✅ 删除页眉、页脚、页码，语义连贯

✅ 保留文档结构：标题、段落、列表

✅ 提取图像、表格、公式（LaTeX）、表格（HTML）

✅ OCR 支持 84 种语言，扫描件也能识别

✅ 输出多格式（Markdown、JSON、中间格式）

✅ 可视化验证（Layout/Span 可视化）

✅ 跨平台支持：Win / Linux / Mac，支持 CPU & GPU 加速



**四、双引擎架构：****Pipeline vs VLM**

- Ø**Pipeline****引擎：精细化专业处理**

Pipeline引擎的技术特色：

- •**模块化设计：**每个AI模型专注于特定任务
- •**高效批处理：**支持GPU批量推理优化
- •**可配置性：**可选择性启用/禁用特定功能
- •**内存优化：**动态显存管理，最低6GB即可运行



- Ø**VLM****引擎：端到端智能理解**

VLM引擎的革命性特点：

- •**单模型解决：**一个模型搞定所有任务
- •**端到端学习：**直接从像素到结构化输出
- •**推理速度：**通过SGLang加速，单卡4090可达10,000 token/s
- •**小而强大：**不到1B参数即可超越72B级别VLM
